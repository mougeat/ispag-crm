# ISPAG CRM 👥

Module de gestion de la relation client intégré à l'écosystème WordPress d'ISPAG.

## Fonctionnalités
- Centralisation des fiches clients (Suisse/France).
- Historique complet des interactions et des devis.
- Segmentation des clients par type d'industrie ou besoins énergétiques.
- Liaison directe avec les projets en cours de fabrication.
